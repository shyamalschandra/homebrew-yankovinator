# Homebrew tap: shyamalschandra/yankovinator

Install [Yankovinator](https://github.com/shyamalschandra/Yankovinator) on macOS:

```bash
brew tap shyamalschandra/yankovinator
brew install yankovinator
yankovinator --version
```

Upgrade:

```bash
brew update
brew upgrade yankovinator
```

Binaries: `yankovinator`, `yankovinator-tui`, `keyword-generator`, `benchmark`.

Requires [Ollama](https://ollama.com) with a pulled model (default `llama3.2:3b`).

Site: https://shyamalschandra.github.io/Yankovinator/
